## A. 资质与主体（阻塞项，只有你能做）

| # | 事项 | 关键点 | 预计耗时 |
|---|---|---|---|
| A1 | **微信认证** | 企业/个体工商户主体 **300 元/次**；是「选类目」和「备案」的**前置条件**，没认证这两项都填不了 | 1~5 工作日 |
| A2 | **ICP 备案** | 2023-09 起强制。**没备案连代码提审都过不了**（错误码 `86369 小程序上架需先完成备案`）。路径：mp 后台 → 设置 → 小程序备案 | 平台初审 1~2 天 + 管局 7~20 工作日 |
| A3 | **服务类目** | 二手交易须选「电商平台 → 二手交易」，**要求企业主体 + 资质**。个人主体上不了这个类目。⚠️ **新增的「校园跑腿」会让类目选择变复杂**：代取快递/代买属于「生活服务」范畴，跟二手交易不是同一个类目，详见下面 A6 | 随认证 |
| A4 | 小程序名称 / 头像 / 简介 | 名称不得含前置审批关键词（金融、医药、新闻、教育、商城、商贸等） | 1 天 |
| A5 | 上线后公开展示备案号 | 备案通过后需在「更多资料」里公开 | — |
| A6 | **跑腿功能的类目风险** | 「校园跑腿」（代取快递、代买、代送）在审核口径里更接近**生活服务 / 跑腿服务**，而不是二手交易。若只报「二手交易」类目，可能被判「实际功能与所选类目不符」。建议二选一：① 提审时把跑腿功能说清楚，看审核要求补类目/资质；② 若拿不到资质，**先只上线二手交易**，跑腿用「体验版」给同学用 | 需确认 |

> **A2 有个容易漏的环节**：平台初审通过后，工信部（号码 **12381**）会发核验短信，
> **必须在 24 小时内**去工信部备案系统完成短信核验，否则申请被自动退回、要重新提交。
> 审核期间还会电话核实（0755 / 021 开头），保持手机畅通。

**课设 / 练手场景**：如果拿不到企业主体，就别走二手交易类目——用「工具」类目 + 限本校使用，
或者干脆只出**体验版**不发布。别等代码打磨完才发现上不了线。
