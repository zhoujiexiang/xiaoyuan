# 初始化指南（详细版）

> **只想快点跑起来？** 看 [`../开始使用.md`](../开始使用.md)，只有 3 步。
> 这份是详细版，含原理说明和完整排查，适合第一次接触云开发的人。

---

## 第 1 步：创建云开发环境

1. 用微信开发者工具导入本项目（目录选 `campus-market`）
2. 顶部菜单 → **云开发** → 开通（选按量付费，学生项目基本在免费额度内）
3. 记下环境 ID，形如 `cloud1-8gxxxxxx`

## 第 2 步：填写配置

打开 **`miniprogram/config.js`**，改前两项：

```js
envId: 'your-env-id',   // ← 你的环境 ID
school: '广西生态工程职业技术学院',  // ← 已设置，换学校改这里
```

**没填环境 ID 会弹窗提示**，不会静默白屏（这是早期版本最大的坑，已修）。

顺手把 `categories` 按需增删。**面交地点不用配**——发布时由用户自己打字描述。

> **为什么学校名不放在登录页让用户选**：用户手选容易填成「XX大学」「xx大学」「XX 大学」，
> 一旦不统一，同校过滤就失效了。统一从 config 读，全校一致。

## 第 3 步：部署云函数

在 `cloudfunctions/` 下逐个文件夹**右键 → 上传并部署：云端安装依赖**：

```
user      product    order      message
upload    admin      init
```

> 必须选「云端安装依赖」。选「本地安装」会因缺 node_modules 失败，
> 报错是 `Cannot find module 'wx-server-sdk'`。

## 第 4 步：一键初始化数据库

云开发控制台 → 云函数 → `init` → **云端测试** → 传入 `{}` → 执行。

返回结果会包含：
- 6 个集合的创建情况（`created` 新建 / `exists` 已存在）
- 一份索引清单

**这个函数是幂等的**，可以重复执行，已存在的集合会跳过。

## 第 5 步：建索引

云开发控制台 → 数据库 → 各集合 → **索引管理**，按下表建：

### products

| 索引名 | 字段 | 唯一 |
|---|---|---|
| `idx_list` | `schoolId` 升序, `status` 升序, `createdAt` 降序 | 否 |
| `idx_cate` | `categoryId` 升序, `schoolId` 升序, `status` 升序, `createdAt` 降序 | 否 |
| `idx_mine` | `sellerId` 升序, `status` 升序, `createdAt` 降序 | 否 |

### orders

| 索引名 | 字段 | 唯一 |
|---|---|---|
| `idx_buyer` | `buyerOpenid` 升序, `status` 升序, `createdAt` 降序 | 否 |
| `idx_seller` | `sellerOpenid` 升序, `status` 升序, `createdAt` 降序 | 否 |
| `idx_product` | `productId` 升序, `status` 升序 | 否 |
| `idx_order_no` | `orderNo` 升序 | **是** |

### messages

| 索引名 | 字段 | 唯一 |
|---|---|---|
| `idx_conv` | `conversationId` 升序, `createdAt` 降序 | 否 |
| `idx_unread` | `toOpenid` 升序, `read` 升序, `createdAt` 降序 | 否 |

### favorites

| 索引名 | 字段 | 唯一 |
|---|---|---|
| `idx_user_product` | `userId` 升序, `productId` 升序 | **是** |
| `idx_user_time` | `userId` 升序, `createdAt` 降序 | 否 |

### users / reports

| 集合 | 索引名 | 字段 | 唯一 |
|---|---|---|---|
| users | `idx_school_verify` | `schoolId` 升序, `verifyStatus` 升序 | 否 |
| users | `idx_student_no` | `studentNo` 升序 | 否 |
| reports | `idx_status_time` | `status` 升序, `createdAt` 降序 | 否 |

> **为什么不自动建索引**：云开发 SDK 没有创建索引的 API，官方只在 HTTP API 里提供，
> 而 HTTP API 需要 AppID + AppSecret 换 access_token，云函数里拿不到。
> 所以 `init` 负责建集合，索引需要手建一次（只建一次，之后不用管）。
>
> **不建也能跑**，只是数据量上千后列表变慢。

## 第 6 步：配置权限规则

打开 `docs/03-数据库权限规则.json`，**逐个集合**在「权限设置 → 自定义安全规则」里粘贴对应片段。

| 集合 | 权限要点 |
|---|---|
| `users` | 只读自己，不可写 |
| `products` | 所有人可读，只能改自己的 |
| `orders` | 只有买卖双方可读，不可写 |
| `messages` | 只有收发双方可读，不可写 |
| `favorites` | 只有自己可读可写 |
| `reports` | 只读自己，不可写 |
| `config` | **仅管理端可读**（存放管理员名单） |

> `config` 集合存放管理员名单，在控制台手动建一下即可（`init` 不管它）。

## 第 7 步：开通内容安全接口

微信公众平台 → 开发 → 开发管理 → 接口设置，确认这两个已开通：

- `security.msgSecCheck`（文字检测）
- `security.imgSecCheck`（图片检测）

> 个人主体小程序默认有。企业主体可能需要单独申请。

## 第 8 步：成为管理员

**不用做任何配置**。第一个打开管理后台的人自动成为管理员（自举机制）。

流程：
1. 登录小程序 → 「我的」
2. 点「🛠️ 管理后台」（进去即成为管理员）
3. 你的 openid 会被写入 `config/admin` 文档

**加其他管理员**：云开发控制台 → 数据库 → `config` → `admin` 文档 → 往 `openids` 数组追加。

```json
{
  "_id": "admin",
  "openids": ["oAAA...", "oBBB..."],
  "createdAt": "2026-09-16T12:00:00.000Z"
}
```

> 名单放数据库而不是写死在代码里，**加管理员不用改代码、不用重新部署**。

## 第 9 步：跑起来验收

1. 编译预览 → 「微信一键登录」→ 授权昵称头像
2. 「我的」→「校园认证」→ 填姓名学号提交
3. 「我的」→「管理后台」→「认证审核」→ 通过
4. 「发布」→ 传图填信息提交
5. 首页能看到商品
6. 换个账号下单 → 卖家在「我卖出的」确认交易 → 双方聊天约面交 → 确认完成

走完这 6 步，整条链路就通了。

## 常见问题

### 弹窗「还没配置云环境」

`config.js` 的 `envId` 没改。这是最常见的坑，所以加了显式提示。

### 云函数调用超时 / `cloud.init` 失败

同上，环境 ID 不对。

### 报 `Cannot find module 'wx-server-sdk'`

部署时选了「本地安装依赖」。重新右键 →「上传并部署：云端安装依赖」。

### 首页空白，没有报错

按顺序查：
1. `products` 集合权限是否设成「所有用户可读」
2. 商品的 `schoolId` 和你的账号是否一致（都来自 `config.js` 的 `school`）
3. 数据库里确实有 `status: 'on_sale'` 的商品吗

### 发布提示「请先完成校园认证」

设计如此。发布需要 `verifyStatus === 'passed'`，走第 9 步的认证流程。

### 进不了管理后台

`config/admin` 文档已存在且你的 openid 不在里面。两种解法：
- 把这个文档删掉，重新进（会重新自举，第一个进的人成为管理员）
- 手动把你的 openid 加进 `openids` 数组

### 聊天收不到新消息

1. `messages` 权限要设成自定义规则（收发双方可读），不能是「仅创建者可读写」
2. `watch()` 需要基础库 2.8.1+，检查调试基础库版本
3. 看控制台有没有 `chat watch error` 日志

### 内容安全接口报 `errCode: 61010` 或超时

接口有频率限制。当前代码在异常时**降级放行**（记日志但不阻断用户），
不影响功能，但日志里的记录可能需要人工复查。

### 列表越翻越慢

索引没建。回到第 5 步。

### 认证审核页看不到申请

确认申请人状态是 `pending`。如果你手动改过数据库，状态可能已经变了。

## 上线前检查清单

- [ ] `config.js` 的 `envId`、`school`、`categories` 都改成本校的
- [ ] 7 个云函数全部部署成功
- [ ] `init` 执行过，6 个集合都在
- [ ] 索引已建（尤其两个唯一索引）
- [ ] 权限规则已配（含 `config` 集合）
- [ ] 内容安全接口已开通
- [ ] 管理员名单已确认，`config/openids` 只留该有的人
- [ ] 用户协议内容按实际情况改过
- [ ] 完整流程测过：登录 → 认证 → 发布 → 下单 → 聊天 → 完成
- [ ] 小程序名称、简介、类目已在小程序后台提交审核

### 类目提醒

二手交易类小程序，微信要求选 **「电商平台 → 二手交易」**，且**需要企业主体 + 资质**。

个人主体小程序上不了这个类目。课设/练手的话：用「工具」类目 + 限制本校使用，
或只提交体验版不发布。

**建议提前确认，别等代码写完了发现上不了线。**
